# Texto para incorporar al informe: anexos de código fuente

Como complemento del cuaderno de Google Colab, el proyecto incluye los archivos de código fuente en formato Python (`.py`), organizados para facilitar su consulta, reutilización y mantenimiento. Los módulos principales se encuentran en la carpeta `src/`: `aplicaciones.py`, `espacios_vectoriales.py`, `gamificacion.py`, `matrices.py`, `sistemas.py`, `transformaciones.py` y `vectores.py`. Además, se adjunta el archivo `celdas_colab_sistemas.py` como apoyo para el trabajo desarrollado en Google Colab.

El repositorio también contiene archivos de prueba independientes: `test_aplicaciones.py`, `test_espacios_vectoriales.py`, `test_gamificacion.py`, `test_matrices.py`, `test_sistemas.py`, `test_transformaciones.py` y `test_vectores.py`. Estos archivos permiten ejecutar comprobaciones sobre los módulos correspondientes. En consecuencia, el código fuente y las pruebas se entregan como anexos digitales junto con el notebook `Transforma_Tec_Reto_Final.ipynb`.

**Ubicación de los anexos:** carpeta `src/` y directorio raíz del proyecto.  
**Evidencia de entrega:** archivos `.py` incluidos en el repositorio comprimido y disponibles para su revisión.
